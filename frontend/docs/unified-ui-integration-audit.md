# Sentinel Edge Unified UI Integration Audit

Last updated: 2026-07-02

## Integrated In The Unified Shell

- App entry: `src/App.tsx` mounts `SentinelEdgeUnifiedShell`.
- Legacy Console navigation: removed from the new shell; old source files remain in place.
- Brand subtitle: top-left copy reads `Risk Control Brain`.
- Backend wiring: health, liveness, readiness, provider health, market-data provider status, Pulse status, Pulse handoff schema, Pulse account, Pulse positions, Pulse queue, stats, tickers, decisions, correlation, automation, kill switch, ORB, chart workspace, market-map context, markets, rate limits, scheduler pause/resume, ticker automation, Pulse trailing stop, Pulse emergency exit, and support/resistance evaluation. The backend route-contract pytest now checks every public `ApiClient` method in `src/lib/api.ts` against the current FastAPI OpenAPI path table.
- Support/resistance: Key Levels Monitor uses `/api/support-resistance/evaluate` with current chart bars and price, then falls back to chart workspace, ORB, OHLCV, and price bands.
- Symbol switching: the active symbol is always the first Key Levels Monitor row, symbol-specific chart/S/R/ORB/market-map payloads are ignored if they belong to a previously selected symbol, and stale async refresh completions cannot overwrite the current symbol snapshot.
- Heatmap: GEX/VEX/VOL mode switch, support/resistance/spot lines, flow paths, volume bars, tooltip, scoped refresh, JSON snapshot export, and expanded popout.
- Popouts: heatmap, gamma by strike, breakout radar, risk brain, and key levels.
- Bot ecosystem: Sentinel Pulse, Tandem Suite, Sentinel Edge, Consolidation, APK Alerts, Darkpool Mon, Extension External, Futures Bot, and Auto-Crypto. Consolidation consumes provider-health rows even when the backend returns them as an object map.
- Provider/Readiness Details: renders all readiness check details when the backend is ready, failing checks first when present, provider-health object maps, and market-data provider labels/configuration status.
- Pulse context: renders Pulse Queue/Positions rows when present, falls back to queue status metadata such as queue size, default TTL, and emergency TTL when the queue endpoint returns metadata instead of item rows, and surfaces the Pulse handoff contract version, recommended endpoint, and Idempotency-Key header state from `/api/pulse/handoff/schema`.
- Protection controls: scheduler pause/resume, automation mode, per-ticker handoff, trailing-stop bridge, emergency-exit bridge, kill switch, add ticker, and remove ticker.
- Kill-switch status: recognizes `kill_switch_active`, `killSwitchActive`, `enabled`, `active`, and boolean-like `state` values so read-only status payloads correctly drive the Pulse Gate KPI and risk penalty.
- Automation mode updates send a minimal settings patch (`{ mode }`) to `/api/automation`; the live probe intercepts paper and recommend-only mode changes without mutating the real backend state.
- Symbol-bearing routes encode ticker symbols before calling ticker add/remove/config, ORB, chart workspace, market-map context, per-ticker automation, Pulse trailing-stop, and Pulse emergency-exit endpoints.
- Legacy advisory controls: prediction horizon, Arm Trigger, Risk Sweep, Convert Alert, Mute Watch, Diagnostics, Ack Alerts, Lock Buys, Advise Stops, Reduce Size, Inject Break, Allow Guarded Breakout, Block Buy Below Support, Reduce Size On Heat Spike, Resimulate Greeks, and Export Levels are recovered as local advisory controls in Protection Operations and written into the operator audit trail.
- Operator audit: All Activity, Operator, and Backend/System filters are integrated; audit export retains the full recovered-control sequence, so repeated advisory actions are visible in exported JSON instead of being limited to the latest few rows.
- Recovered dashboard modules: Trading Overview, Scanner Workbench, Advisor Health, Experience, Protection Ops, P&L Tracking, Market Coverage, Portfolio, System Settings, and Tutorials are reachable from Operations Modules without restoring the Legacy Console route. The live probe now exercises Scanner Workbench watch-intent validation, Experience RUM status visibility, and System Settings operator notification/Pulse contract panels.
- Chart Workspace compatibility: saved Simulation Lab result metrics keep explicit labels, summary provenance titles, ratio/percent display modes, and type-safe formatting so the recovered Market Map/Chart Workspace surfaces continue to satisfy their static contract while the unified shell is the default entry point.
- Stability hardening: recovered modules lazy-load behind a module error boundary, and `TickerCard` tolerates null live numeric fields.

## Preserved By Design

- `src/components/asset-command/**` is still present for review and rollback.
- The old asset-command layout test still exists because it documents the legacy source surface until deletion is approved.
- Standalone preview assets remain in the integration pack as non-installed static design references; they are not copied into the repo by the installer.
- Old UI iteration lab controls remain preserved in `asset-command` source only; they are design/prototype controls, not production bot controls.
- Old local-state controls for metric reels, the configurable hex core heatmap, ticker-wheel picking, Pause/Resume feed, Apply settings, and Pulse startup choice (`Standalone Mode` / `Bridge mode`) remain preserved in `asset-command` source. Production equivalents in the new shell are the live symbol selector, backend-driven key levels, heatmap mode/refresh/export controls, topbar Live/Pause, Local Settings polling/heat-mode controls, Pulse/provider health panels, and the audit filter/export workflow.
- Old directive labels map to the new shell as follows: Run sweep maps to Risk Sweep, Export ledger maps to Export Audit Log, Emergency lock maps to Kill Switch plus the Pulse Emergency Exit bridge confirmation, and chart/Greek workbench controls map to the recovered Chart Directives and Greek Workbench cards.
- Old static sample bridge rows for Discord Trading Bot, Sentinel Chain, Sentinel Core, and Sentinel Echo are preserved only in legacy `asset-command` seed data. The new shell uses the requested mesh: Sentinel Pulse, Tandem Suite, Sentinel Edge, Consolidation, APK Alerts, Darkpool Mon, Extension External, Futures Bot, and Auto-Crypto.
